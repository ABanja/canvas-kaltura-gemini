Kaltura Gemini Assistant

Gemini API

Create a key at Google AI Studio. It is stored only in this browser profile (chrome.storage.local) and is sent only to generativelanguage.googleapis.com.

Video & transcript

A language code or name such as en or Spanish.

Only used when a video has no captions and you choose to send the video file itself. The file is uploaded to the Gemini File API and deleted by Google after 48 hours.

Extra Kaltura domains

Players on *.kaltura.com work out of the box. If your school serves Kaltura from its own domain (for example mediaspace.myschool.edu or *.myschool.edu), add it here, one per line. Chrome will ask you to grant access.

Privacy

When you use the assistant, the video's transcript (or, if you choose, the video file) and your questions are sent to Google's Gemini API under your own API key and Google's terms. Nothing is sent to the extension's authors. Check your institution's policies before sending course material to third-party AI services.
